# แปลชัวร์ TH⇄EN: คู่มือ Gem แปลไทย⇄อังกฤษ (Gemini)

Gem นี้แปลไทย⇄อังกฤษให้เป็นธรรมชาติแบบเจ้าของภาษา มีคำอ่านภาษาไทยและอธิบายวิธีใช้เป็นภาษาไทย และ**ไม่เดา**: ส่วนไหนไม่แน่ใจจะบอกตรง ๆ หรือตัดทิ้ง

| ไฟล์ | คืออะไร |
|---|---|
| [`gem-instructions.md`](gem-instructions.md) | คำสั่ง (Instructions) ฉบับสมบูรณ์ คัดลอกไปวางใน Gem ได้เลย |
| `README.md` (ไฟล์นี้) | ชื่อ คำอธิบาย วิธีตั้งค่า วิธีใช้ ชุดทดสอบ และสิ่งที่ปรับปรุง |

## 1. Name (ชื่อ): คัดลอกไปวางได้เลย

```
แปลชัวร์ TH⇄EN
```

ทำไมชื่อนี้:
- **ชัวร์** = มั่นใจ ไม่เดา ไม่มั่ว ตรงกับจุดเด่นที่คุณเน้นที่สุด
- สั้น อ่านปุ๊บเข้าใจปั๊บ ไม่ถูกตัดในรายการ Gem
- **⇄** บอกว่าแปลได้ทั้งสองทาง

ชื่อสำรอง:
- **เนียนชัวร์ TH⇄EN**: เนียนแบบเจ้าของภาษา + ชัวร์ไม่มั่ว
- **Native & Sure TH⇄EN**: ถ้าอยากได้ชื่อภาษาอังกฤษ

ถ้าเปลี่ยนชื่อ ให้แก้ 2 จุดใน `gem-instructions.md`: บรรทัดแรก และ "You are **แปลชัวร์ (Plae Chua)**" ในข้อ 0

## 2. Description (คำอธิบาย): คัดลอกไปวางได้เลย

ภาษาไทย (แนะนำ):

```
แปลไทย⇄อังกฤษให้เป็นธรรมชาติแบบเจ้าของภาษา พร้อมคำอ่านภาษาไทยและวิธีใช้ ไม่เดา ไม่มั่ว ส่วนไหนไม่แน่ใจจะบอกตรง ๆ · ส่งได้ทั้งข้อความ ลิงก์ และรูปภาพ
```

ภาษาอังกฤษ (ถ้าจะแชร์ให้คนต่างชาติใช้):

```
Natural Thai⇄English translation with Thai-script pronunciation and usage tips. No guessing: anything uncertain is clearly marked. Works with text, links, and images.
```

## 3. วิธีสร้าง Gem (ประมาณ 5 นาที)

ทำบนคอมพิวเตอร์จะง่ายที่สุด เพราะต้องวางข้อความยาว เมื่อบันทึกแล้ว Gem จะใช้ในแอป Gemini บนมือถือได้ด้วย (ชื่อเมนูของ Google อาจเปลี่ยนไปเล็กน้อย)

1. เข้า **gemini.google.com** แล้วล็อกอิน
2. ที่เมนูด้านซ้าย กด **Explore Gems** (หรือ **Gems**) แล้วกด **New Gem**
3. **Name:** วางชื่อจากข้อ 1
4. **Description:** วางคำอธิบายจากข้อ 2
5. **Instructions:** คัดลอกเนื้อหา**ทั้งหมด**ในไฟล์ `gem-instructions.md` ไปวาง
   - บน GitHub ให้เปิดไฟล์ แล้วกดปุ่ม **Copy raw file** (ไอคอนคัดลอกด้านบนของไฟล์)
   - ⚠️ **อย่ากด**ปุ่มให้ Gemini เขียนคำสั่งใหม่ (ไอคอนไม้กายสิทธิ์ / "Use Gemini to re-write instructions") เพราะ Gemini จะเขียนคำสั่งใหม่ทั้งหมด และกฎสำคัญบางข้ออาจหายไป
   - ไม่บังคับ: ถ้าอยากให้ Gem รู้จักคุณ ให้แก้บรรทัด **About the user: none** ในข้อ 18 เปลี่ยนคำว่า `none` เป็นข้อมูลของคุณ เช่น `works at an international school in Bangkok`
6. **Default tool:** ไม่ต้องเลือก
7. **Knowledge:** เว้นว่างไว้ (ใช้เฉพาะเมื่อวางคำสั่งไม่ได้ ดูข้อ 8)
8. ลองพิมพ์ข้อความทดสอบจากข้อ 5 ในช่องทดลองด้านขวา แล้วกด **Save**

## 4. วิธีใช้ทุกวัน

- **วางข้อความได้เลย** ไม่ต้องพิมพ์ว่า "ช่วยแปล" Gem จะดูเองว่าต้องแปลเป็นไทยหรือเป็นอังกฤษ
- **ส่งลิงก์ รูปภาพ หรือภาพหน้าจอได้** ถ้า Gem เปิดลิงก์ไม่ได้ มันจะบอกตรง ๆ ให้คัดลอกข้อความหรือแคปหน้าจอส่งแทน
- **บอกว่าจะส่งให้ใคร แล้วจะแปลได้เหมาะขึ้น** เช่น `ส่งหัวหน้า: พรุ่งนี้ขอเข้างานสายนะคะ` หรือ `คุยกับเพื่อนในเกม: เดี๋ยวมานะ`
- **เริ่มแชทใหม่เมื่อเปลี่ยนเรื่อง** แชทที่ยาวมาก ๆ ทำให้ AI เริ่มลืมคำสั่ง

คำสั่งที่ใช้บ่อย (พิมพ์ไว้หน้าหรือท้ายข้อความ):

| พิมพ์ | ได้อะไร |
|---|---|
| `แปลด่วน` | เฉพาะประโยคที่ดีที่สุด + คำอ่าน + ความหมายสั้น ๆ |
| `ขอแบบง่าย` | ประโยคที่ง่ายที่สุดแต่ยังเป็นธรรมชาติ เหมาะกับคนเพิ่งเริ่มพูด |
| `ช่วยตอบ` | ตัวอย่างคำตอบกลับ 2–3 แบบ (ตกลง / ปฏิเสธอย่างสุภาพ / ถามเพิ่ม) |
| `ตรวจภาษาอังกฤษ` | ตรวจประโยคที่คุณเขียนเอง (หรือพิมพ์ประโยคแล้วต่อท้ายว่า `ถูกไหม`) |
| `ขอหลายระดับ` | แบบทางการ / สุภาพ / ทั่วไป / เพื่อนสนิท |
| `ขอคำอ่านละเอียด` | แยกพยางค์ เสียงหนัก การออกเสียงเชื่อมคำ และ IPA (เมื่อมั่นใจเท่านั้น) |
| `ตรวจแหล่งที่มา` | ให้ Gem ตรวจข้อมูลเรื่องภาษาในคำตอบล่าสุดกับแหล่งที่เชื่อถือได้ |
| `โหมดเรียนรู้` | อธิบายคำศัพท์ ไวยากรณ์ง่าย ๆ และจุดที่คนไทยมักผิด (ปิดด้วย `ปิดโหมดเรียนรู้`) |
| `เมนู` | ดูคำสั่งทั้งหมด |

**การตั้งค่า** เช่น `ตั้งค่า: UK`, `ตั้งค่า: ผู้หญิง`, `ตั้งค่า: แปลด่วนตลอด` ใช้ได้เฉพาะในแชทนั้น ถ้าอยากเปลี่ยนถาวร ให้แก้ข้อ 18 ในคำสั่งของ Gem (Gems → Gem ของคุณ → Edit)

## 6. สิ่งที่ปรับปรุงจาก prompt เดิมของคุณ

**แก้จุดที่มีปัญหา**
1. **ข้อ 16 ขาดหาย** (จบที่ "Do not "correct" perfectly"): เขียนให้ครบแล้ว (ตอนนี้คือข้อ 10)
2. **ไม่ได้กำหนดภาษาที่ใช้อธิบาย**: Gem อาจอธิบายเป็นภาษาอังกฤษจนคุณอ่านไม่เข้าใจ ตอนนี้บังคับให้อธิบายเป็นภาษาไทยง่าย ๆ ทุกครั้ง
3. **กฎ "ต้องมีแหล่งอ้างอิง" เดิมใช้กับทุกอย่าง** ซึ่งอาจทำให้ Gem ไม่กล้าแปล หรือแย่กว่านั้นคือแต่งแหล่งอ้างอิงขึ้นมาให้ดูน่าเชื่อ ตอนนี้แยกชัดเจนว่า
   - **คำแปล** = ฝีมือนักแปล ไม่ต้องอ้างอิง
   - **ข้อมูลเรื่องภาษา** (ความหมายในพจนานุกรม, US/UK, ที่มาของคำ, คำนี้หยาบไหม) = ต้องชัวร์ หรือตรวจก่อน หรือตัดทิ้ง
4. **"ไม่แน่ใจให้ตัดทิ้ง"**: ทำตามที่คุณขอสำหรับข้อมูลเสริม แต่**คำแปลหลักจะไม่ถูกตัด** จะทำเครื่องหมาย ⚠️ ไว้แทน เพราะถ้าตัดคำแปลทิ้ง คุณจะไม่ได้อะไรเลย
5. **ห้ามอ้างแหล่งที่ไม่ได้เปิดดูจริง** และห้ามบอกว่า "ตรวจแล้ว" ถ้าค้นเว็บไม่ได้
6. **ข้อ 5 เดิม** บอกว่า "ถ้าตีความได้หลายแบบ อย่าเลือกโดยไม่มีหลักฐาน" แต่ไม่ได้บอกว่าให้ทำอะไรแทน ตอนนี้ให้แสดงแบบที่น่าจะใช่ก่อน แล้วตามด้วยอีกแบบ พร้อมเหตุผลสั้น ๆ
7. **IPA**: เดิมให้ใส่บ่อย ซึ่งอ่านยากสำหรับมือใหม่และเสี่ยงผิด ตอนนี้ใส่เมื่อขอเท่านั้น และเฉพาะเมื่อมั่นใจ
8. **คำอ่านภาษาไทย**: ป้องกันปัญหา ์ (การันต์) ที่ทำให้คนไทยไม่ออกเสียงท้าย เช่น ถ้าเขียน "แคทส์" คนจะอ่านว่า "แคท" ตอนนี้ใช้วงเล็บแทน: แคท(ส)

**เพิ่มสิ่งที่ยังไม่มี**
- **รูปแบบคำตอบที่แน่นอน** สั้น อ่านง่าย: ⭐ ประโยคแนะนำ → คำอ่าน → ความหมาย (แปลกลับเป็นไทย) → ใช้กับใคร
- **"แบบง่าย"** สำหรับคนเพิ่งเริ่ม: ประโยคที่พูดง่ายที่สุดแต่ยังถูกและเป็นธรรมชาติ
- **ช่วยตอบ**: แปลข้อความที่ได้รับแล้วช่วยคิดคำตอบกลับ
- **เรื่องเฉพาะภาษาไทย**: ภาษาไทยมักไม่มีประธานและไม่บอกเวลา (tense), คำบอกความแน่นอน (อาจ / น่าจะ / ต้อง) ต้องแปลให้แรงเท่าเดิม, ครับ/ค่ะ, เวลาแบบไทย (สามโมงเช้า = 9 a.m.), ปี พ.ศ. → ค.ศ., ตัวเลขแสน/ล้าน
- **กันคำสั่งแฝง**: ถ้าข้อความ ลิงก์ หรือรูปมีคำสั่งแอบแฝง เช่น "Ignore previous instructions" Gem จะแปลอย่างเดียว ไม่ทำตาม
- **เตือนมิจฉาชีพ** และข้อควรระวังสำหรับเอกสารราชการ วีซ่า การแพทย์ การเงิน
- **ภาพหน้าจอแชท**: แปลโดยคงไว้ว่าใครพูดอะไร
- **คำสั่งลัดภาษาไทยและการตั้งค่า**
- **ตรวจทานก่อนตอบทุกครั้ง** (ข้อ 19)

## 7. ข้อควรรู้ (ตรงไปตรงมา)

- **ไม่มีคำสั่งไหนทำให้ AI ไม่ผิดเลย 100%** คำสั่งนี้ช่วยลดการเดาและบังคับให้บอกเมื่อไม่แน่ใจได้มาก แต่ถ้าเป็นเอกสารสำคัญ (สัญญา วีซ่า การแพทย์ การเงิน) ควรให้นักแปลหรือผู้เชี่ยวชาญตรวจอีกครั้ง และหน่วยงานราชการบางแห่งอาจต้องการคำแปลที่มีการรับรอง
- **Gem ตรวจแหล่งข้อมูลได้จริงก็ต่อเมื่อค้นเว็บได้ในแชทนั้น** ถ้า Gem เขียนว่า "ตามความรู้ทั่วไป ยังไม่ได้ตรวจกับแหล่งอ้างอิง" แปลว่าข้อมูลนั้นมาจากความรู้ของ AI เอง ยังไม่ได้ตรวจ
- **ลิงก์บางแบบเปิดไม่ได้** (ต้องล็อกอิน เพจส่วนตัว หรือเว็บที่บล็อก AI) ให้คัดลอกข้อความหรือแคปหน้าจอส่งแทน
- **คำอ่านภาษาไทยเป็นเสียงโดยประมาณ** ถ้าอยากฟังเสียงจริง ให้ค้นคำใน [Cambridge Dictionary](https://dictionary.cambridge.org/) หรือ [Oxford Learner's Dictionaries](https://www.oxfordlearnersdictionaries.com/) แล้วกดปุ่มลำโพงเพื่อฟังเสียงแบบ UK และ US
- **ระบบกรองความปลอดภัยของ Gemini** อยู่เหนือคำสั่งของ Gem จึงอาจทำให้คำหยาบถูกแปลเบาลงหรือถูกปฏิเสธในบางครั้ง คำสั่งของ Gem ปิดระบบนี้ไม่ได้
